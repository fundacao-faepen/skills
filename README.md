# Skills da Fundação FAEPEN

Skills internas e simples para tarefas recorrentes da Fundação FAEPEN.

## Skills

- `consultar-cpf-receita`: consulta situação cadastral no portal da Receita Federal e registra retornos em JSON local cumulativo.
- `post-aniversario`: gera a arte de aniversário de colaboradores para o feed do Instagram.
- `vaga-instagram`: gera artes e legenda para divulgar vagas de estágio no Instagram.

Cada skill fica em seu próprio diretório, com um `SKILL.md` e os arquivos que ela utiliza. Este repositório não é um plugin e não possui instalador.
